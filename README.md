## 📌 重要仓库 — QDU-Nav（2026.08）

把教务公告、比赛报名、讲座通知……散在 15+ 校园站点里的信息抓到一个手机页里，一个**校园导航站**。
Vue 3 + Vite 前端，Python 定时抓教务处官网数据；跑 7 学院约 5 个公众号接口，GitHub Actions 每 6 小时自动刷新课表，部署在 GitHub Pages。

[![repo](https://github-readme-stats-own-xi.vercel.app/api/pin/?username=IceofTea&repo=QDU-Nav&theme=radical&hide_border=true)](https://github.com/IceofTea/QDU-Nav)
[![site](https://img.shields.io/badge/site-QDU--Nav%20Pages-00d4ff?style=for-the-badge&logo=github&logoColor=white&labelColor=0a1a2f)](https://iceoftea.github.io/QDU-Nav/)

- 🛰️ **间接通信链路**：Python 抓包 + Node 渲染双实现，任何浏览器点链接即达，不依赖任何 API
- 🧩 **模块化接入**：数据源 ⇒ 适配器 ⇒ 应用层，新增校园站只写一个适配器
